# VictimLens — Victim Rights & Support

VictimLens is a web application focused on victimology, victim rights, and access to support resources. It aims to help visitors understand victimization, explore victims' rights, and discover relevant information about justice and support.

## Overview

Understanding victimization and knowing where to find reliable information can be challenging. VictimLens brings relevant information together in an accessible web interface.

## Features

- **Victimology Explorer:** Explore information about victimology and victimization.
- **Types of Victimization:** Learn about different types of victimization.
- **Victim Rights:** Explore information about victims' rights and protections.
- **Support Resources:** Find relevant information and support resources.
- **Responsive Interface:** Navigate the website across supported screen sizes.
- **Interactive Design:** Explore the website through its interactive interface.

*Features listed above should reflect the functionality implemented in the current version.*

## Getting Started

### Prerequisites

Install Node.js and npm before running the project locally.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/prajwalsmbtech25-lang/Victimology-Website.git
   ```

2. Navigate into the project directory:

   ```bash
   cd Victimology-Website
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
